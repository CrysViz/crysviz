# Storage Information

There are currently three different options for which information is stored on **YOUR device**: 
- **None**: Default settings are restored on reload, structures are not saved. As if you have never been here

- **Minimal** (default): Settings and color choices are stored. Can be deleted with the purge button.

- **Structure**: The structures you are working with are stored in the browser tmp storage on your device. Reload will preserved all settings and loaded structures. This has limitations depending on the browser and device. Usually 50MB. Using the purge button you can delete all stored information 
**Important:** No data is leaving your device unless you connnect to the backend server hosted by the Theoretical Physics Division at Linköping University. If you do so we can at this point not guarantee that filenames or information about your structure are not saved on our server in log files. However, these log files are only used for performance analysis and error tracking, and will be periodically deleted.
