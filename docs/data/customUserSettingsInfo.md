# Custom User Settings

Override the built-in per-element color map, per-element atomic-radius map, and per-pair
bond-distance map — either by loading a JSON file, or by configuring them interactively through
a periodic-table picker. Only the elements or pairs you touch are overridden; everything else
keeps using the app's built-in CrysViz/JMOL defaults. Changes apply immediately to the currently
loaded structure (if any) and are remembered across reloads.
