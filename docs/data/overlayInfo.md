# Structure Overlay & Comparison

Two tabs, sharing the same file-browser checkboxes to pick structures — only one is active at a
time (enabling one turns the other off):

- **Comparison**: check exactly one other row to mark it as the comparison structure. Shows a
  Main/Comp opacity crossfade slider, a bonds-visibility toggle, and (with "Show Lattice
  Comparison" on) lattice/geometry differences against the currently selected structure.
- **Overlay**: check any number of other rows to overlay them all on top of the currently selected
  structure. Each overlaid structure gets its own opacity and bonds-visibility toggle in a
  scrollable table, and its own lattice-comparison plot when "Show Lattice Overlay" is on.
