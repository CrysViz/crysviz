# Bonded neighbours

The **add-neighbour** button (an atom, a faint atom and a +) shows every atom bonded to the selection (by the Bonds-tab lengths) faintly in the
Selection Inspector's view.

- **Click a faint atom** to add it to the selection — in the main 3D view too. The tool stays on and
  now also offers the new atom's neighbours, so you can grow the selection bond by bond.
- **Press the button again, or Esc,** to finish: the faint atoms you did not pick disappear.
- **Add all** adds every bonded neighbour at once.
- **Ctrl/⌘-click** a selected atom in the inspector to remove it; Shift-click atoms in the main
  view adds them.

The view does not move while you add atoms; double-click it to re-centre (on the faint atoms too
while the tool is on).

With **Link periodic copies** on (Atoms tab) a selected atom stands for all its periodic copies, so
a neighbour that is another copy of a selected atom cannot be added — the count says how many there
are. Turn the link off to add them.
