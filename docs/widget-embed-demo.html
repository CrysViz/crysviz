CrysViz widget — trajectory control

The 3D view is an embedded CrysViz widget. The controls below it live on this page and drive the trajectory over postMessage — no reloading, and the camera never re-orients.

— / —

Host → widget: {target:'crysviz-widget', type:'setFrame'|'play'|'pause'|'getState', …}. Widget → host: {source:'crysviz-widget', type:'ready'|'frame'|'state', …}. See the CrysViz README “Widget mode / embedding”.
